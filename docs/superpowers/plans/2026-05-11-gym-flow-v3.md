> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add substitution support, workout finish summaries, exercise history detail, and weekly adherence to the local iOS workout app.

**Architecture:** Keep the feature inside the existing SwiftUI and `LocalAppState` architecture. Add small Codable models in existing model files, derived calculations in `WorkoutPlanner`, and targeted SwiftUI sections in Today and Progress without regenerating the Xcode project.

**Tech Stack:** Swift 6, SwiftUI, Observation, XCTest, local UserDefaults JSON snapshot.
